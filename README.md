# University Analytics Using Python for Data Science

A Streamlit-based dashboard for university student data analysis, visualization, machine learning, and Explainable AI.

## Features
- Dataset upload, preview, and cleaning
- Statistics, probability, and hypothesis testing
- Interactive Plotly visualizations
- Placement prediction and backlog risk analysis
- Student package prediction using Linear Regression
- Explainable AI using permutation importance, model feature importance, partial dependence, and local explanations
- New student registration

## Technologies
Python, Streamlit, Pandas, NumPy, Plotly, SciPy, Scikit-learn, XGBoost

## How to Run
1. Install Python.
2. Install dependencies using `pip install -r requirements.txt`.
3. Run the application using `streamlit run app.py`.
4. Upload a CSV dataset containing the required student columns through the sidebar.

## Note
Use an appropriate dataset with the required columns to explore the dashboard. Predictions depend on the quality and quantity of the uploaded data.
